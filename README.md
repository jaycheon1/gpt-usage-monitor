# GPT Usage Monitor — 1.2.0-beta.1

Windows용 비공식 Codex 계정 사용량 모니터입니다. OpenAI가 제작·보증하는 제품이 아닙니다.

## 다운로드

[Windows 베타 다운로드](https://github.com/jaycheon1/gpt-usage-monitor/releases/tag/v1.2.0-beta.1)

소스 ZIP 대신 릴리스의 Windows ZIP을 사용하세요. 소스에서 실행하려면 Build.ps1로 실행기를 먼저 생성하세요.

## 시작하기
1. 공식 Codex 앱 또는 CLI를 설치하고 **본인 ChatGPT 계정**으로 로그인합니다.
2. 배포 ZIP을 빈 폴더에 **전체 압축 해제**합니다.
3. `UsageMonitor.exe`를 실행합니다. `Start.cmd`도 같은 실행 파일을 엽니다.
4. Codex를 찾지 못하면 화면의 `Codex 위치 선택`에서 공식 설치본의 `codex.exe`를 지정합니다.
5. 창을 닫으면 조회가 종료됩니다. 삭제하려면 이 프로그램 폴더만 삭제하면 됩니다.

## 지원 범위와 설치 조건
- 목표 환경: Windows 10/11, Windows PowerShell 5.1, .NET Framework 4.x 및 WPF. 검증은 제작 PC 한 대에서 수행했습니다. 다른 PC·계정의 호환성을 보장하지 않는 베타입니다.
- 인터넷 연결과 ChatGPT 계정으로 로그인한 Codex가 필요합니다. Codex 자체 파일은 패키지에 포함하지 않습니다.
- macOS/Linux는 지원하지 않습니다. API 키 로그인만 사용하는 경우 계정 한도 정보가 제공되지 않을 수 있습니다.
- app-server 인터페이스와 계정별 응답 필드는 변경될 수 있습니다.
- 별도 모델 호출용 API 키 입력이나 결제가 없습니다. 각 사용자의 계정 한도를 읽습니다.

## 표시와 갱신
- 첫 실행 시 조회 후 **15분마다** 한도·누적 토큰을 조회합니다. 카운트다운은 PC 시계로 매초 계산합니다.
- `지금 새로고침`은 즉시 조회합니다. 일시정지 시 진행 중 요청은 마칠 수 있으며 추가 자동 조회를 멈춥니다. 재개하면 다시 조회합니다.
- 녹색 막대는 잔여 한도 %입니다. 보라색 막대는 한도 기간의 경과율로 충전량이 아닙니다.
- 초기화 시간이 지나도 서버 확인 전 잔여량을 100%로 바꾸지 않습니다.
- 누적 토큰은 서버 집계 기록입니다. 남은 토큰 개수, 모든 ChatGPT 모델의 한도, API 결제 잔액을 뜻하지 않습니다.
- 오류 시 마지막 성공 값과 시간을 유지합니다. 17분 이상 지난 값은 오래된 데이터로 표시합니다.
- 추가 크레딧은 서버 단위 그대로 표시합니다. 초기화권은 개수만 표시하며 소비하지 않습니다.
- 시간은 한국 시간입니다. `항상 위에`로 다른 창 위에 둘 수 있습니다.

## 서명과 보안 정책
이 베타의 EXE와 PowerShell 파일은 **코드 서명되지 않았습니다**. 다운로드 후 SmartScreen, Smart App Control, 회사 정책 또는 PowerShell 실행 정책에 의해 차단될 수 있습니다. 실행기는 번들 스크립트를 실행하는 자식 PowerShell 프로세스에만 ExecutionPolicy Bypass 옵션을 적용합니다. 사용자·컴퓨터의 영구 실행 정책은 변경하지 않으며, 조직 정책이나 SmartScreen 차단을 해제하지 않습니다. 차단되는 환경에서는 정식 서명된 배포본 또는 조직에서 승인한 배포 경로를 사용하세요.

공유 시 ZIP과 함께 `SHA256SUMS.txt`를 배포하세요. 해시는 파일 변경 여부를 확인할 뿐 게시자의 신원을 인증하지 않습니다.

## 업데이트 및 오류 보고
자동 업데이트나 원격 코드 다운로드는 없습니다. 새 버전을 받을 때 기존 창을 닫고 새 폴더에 압축 해제하세요. 계정 인증 정보는 이 프로그램 폴더에 보관하지 않습니다.

배포자에게 프로그램 버전, Windows 버전, Codex 버전, 화면 오류 문구를 전달하세요. 계정 식별자, 인증 파일, API 키, 토큰, 전체 사용 내역은 보내지 마세요. 공개 지원 채널은 아직 지정되지 않았습니다.
